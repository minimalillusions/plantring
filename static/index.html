PlantRing — Grow Light Installer

PlantRing is a small grow light for houseplants: a ring of 24 LEDs on an ESP32-C3 SuperMini, running ESPHome. It works on its own, with its own web page and a daily light schedule, and Home Assistant picks it up automatically if you use it. This page installs the firmware straight from your browser, with nothing to download and nothing to compile.

Install the firmware

You need the ESP32-C3 SuperMini (ring connected or not), a USB data cable, a computer with Chrome or Edge, and a 2.4 GHz WiFi network.

This browser can’t talk to USB devices, so it can’t install the firmware. Open this page on a computer in Google Chrome or Microsoft Edge (Firefox 151 or newer works too). Phones and tablets are not supported.

Installing needs a secure connection. Open https://minimalillusions.github.io/plantring/ instead.

Firmware version

  1. Open this page in Chrome or Edge on a computer.
  2. Plug the ESP32-C3 into the computer with a USB data cable.
  3. Click Install, pick the port and confirm with Install. Writing the firmware takes a minute or two. Not sure which port? Unplug the board and see which entry disappears.
  4. Choose your WiFi and enter its password when asked. It has to be a 2.4 GHz network.
  5. Done. Click Visit Device to open the lamp’s own web page. If you use Home Assistant, it finds the lamp automatically.

After installing

Web page
Open http://plantring-xxxxxx.local (the last six characters differ for every lamp) or the lamp’s IP address from your router, and bookmark it.
Schedule
The light goes on at 07:00 and off at 21:00, time zone Europe/Berlin. Change Timezone, Lights on and Lights off on the lamp’s page, or turn Schedule off to switch by hand. Anything you switch by hand stays until the next scheduled change.
Presets
Preset: Vegetative (blue-rich), Preset: Bloom (red-rich) and Preset: Full spectrum (white) change the color and keep the brightness.
Home Assistant
The lamp shows up under Settings → Devices & services as a discovered ESPHome device and can be added with one click.
Updates
When a new firmware version is out, the Firmware entry on the lamp’s page says so. Install it from Home Assistant (no cable needed), or connect the lamp to your computer, click Install on this page and choose Update. Your WiFi and settings are kept.

Troubleshooting

No port shows up
The USB cable can probably only charge. Try a cable you know carries data. The ESP32-C3 SuperMini needs no driver on Windows 10/11, macOS or Linux; boards with a separate CH340 or CP210x USB chip need that chip’s driver.
The first install fails
Start the board in download mode: unplug it, hold BOOT, plug it back in, release BOOT and click Install again. When it is done, press RESET or unplug and replug the board once.
WiFi won’t connect
The ESP32-C3 only works with 2.4 GHz WiFi; 5 GHz networks are invisible to it. Make sure 2.4 GHz is switched on in your router, check the password, and keep the lamp near the router for the first setup.
The WiFi question never came
Wait a minute: the lamp then opens its own WiFi hotspot, named after the lamp (it starts with “plantring”). Connect to it with your phone and a setup page opens where you pick your WiFi. If it doesn’t open, go to http://192.168.4.1.
The board restarts when the light comes on
A computer’s USB port may not supply enough current for the ring. Run the lamp from a USB charger with at least 1 A (2 A recommended).
